the architecture

Iris treats data compression as a perception problem. Rather than streaming bytes into a dictionary compressor, it views the dataset at once, clusters similar bytes, and encodes those clusters spatially.

visionsort & entropy routing

Binary data is sorted using VisionSort, which builds a probabilistic model and routes data through four branches: NearlyFree, Verify, PlacementSort, or FullSort.

Clustering bytes strips the original order. VisionSort isolates low-entropy regions where the resulting permutation index is nearly deterministic. The rest is compressed via zstd.

the spatial mapping

The sorted stream is packed sequentially into grayscale YUV420p frames. Every byte acts as a luminance value on the Y-plane. Chroma channels remain neutral.

When laid out horizontally, these "images" form massive, stable bands of uniform color. From one frame to the next, time stands conceptually still.

hardware encoding

The raw frames stream via FFmpeg into an NVIDIA GPU. The system negotiates av1_nvenc on RTX 4000+ architectures, falling back to hevc_nvenc on older hardware.

Because the frames are essentially static horizontal blocks, NVENC's motion estimators compress the data instantly with near-zero error. Without NVIDIA, Iris elegantly diverts to the CPU via libsvtav1.
