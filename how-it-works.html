the architecture

At its core, Iris treats data compression as a perception problem. Rather than streaming linear sequences of bytes into a generic dictionary compressor (like LZ77 or DEFLATE), it views the entire dataset at once, clusters similar bytes, and encodes those clusters spatially.

This is achieved in three distinct phases: entropy-based sorting, spatial mapping, and video codec inter-frame prediction.

visionsort & entropy routing

Before any traditional compression occurs, the raw binary data is read into memory and sorted using VisionSort. VisionSort does not just blindly compare bytes. It uses Bayesian within-call learning and entropy-based routing to quickly classify and sort data segments.

By clustering identical and similar bytes together, we maximize the length of contiguous blocks of data that share the same value. Because the data's original order is lost during sorting, we generate a permutation index alongside the sorted data, allowing perfect reconstruction.

// Simplistic representation of the permutation record

    original_position: u64,
    sorted_position: u64,

the spatial mapping

The resulting sorted byte stream is mapped onto a sequence of grayscale video frames. For example, treating every 8-bit byte as a physical pixel's luminance value.

When the highly sorted data is laid out horizontally and wrapped according to frame width, the resulting "images" appear as wide, horizontal bands of uniform color. From one frame to the next, these bands change very slowly in the temporal domain.

av1 lossless encoding

The sequence of frames is handed to an AV1 encoder (such as SVT-AV1 or rav1e) configured for strict lossless encoding. AV1's advanced inter-frame prediction engine is world-class at detecting temporal stability.

Because the generated frames are largely static blocks of grayscale bands, the encoder can predict subsequent frames based on prior frames with near-zero error. This yields extreme compression ratios that typical dictionary compression algorithms struggle to achieve on arbitrary binary data.
