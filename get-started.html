installation

Iris is built in Rust and uses AV1 for software-based encoding. The easiest way to install it is via cargo.

cargo install iris-cli

Alternatively, you can download pre-compiled binaries for Mac, Linux, and Windows from our releases page.

usage

The CLI is designed to be as minimal and straightforward as the algorithm itself.

compressing data

iris compress input.bin output.iris

decompressing data

iris decompress output.iris original.bin

system requirements

Any modern machine. By using AV1 software encoding (like SVT-AV1) instead of hardware-specific solutions, iris avoids tying you to a specific vendor pool.

It runs on Mac, Linux, Windows, AMD, Intel, and Apple Silicon. No GPU is required. If your machine can surf the modern web, it can run iris.
