five stages

01

profile

a single read-only pass measures entropy, autocorrelation at 64 lags, and block fingerprints. nothing is read twice. every downstream stage uses this pass.

02

column grammar

structured text is decomposed by column. timestamps become three u8 arrays. enums become dictionary indices. the result approaches the information-theoretic minimum per field.

03

resonance

periodic structure is extracted via wrapping i8 delta at the dominant lag. three passes maximum. data with a strong period compresses to near-zero residual.

04

prediction graph

similar blocks anywhere in the file are found via SimHash and LSH bands. no window limit. similar blocks stored as XOR deltas. lz77 can't do this.

05

route

entropy decides the codec. below 0.15: bzip2. below 0.80: zstd. above: AV1 via NVENC GPU. the codec matches the signal.

usage

iris compress input.log output.iris

compress an input file into the custom iris format

iris decompress output.iris recovered.log

reconstruct the exact original bytes

iris info output.iris

inspect how the file was routed without fully decompressing it
