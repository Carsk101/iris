installation

Iris is built in Rust and uses FFmpeg for orchestration. The easiest way to install it is via cargo.

cargo install iris-cli

Alternatively, you can download pre-compiled binaries for Mac, Linux, and Windows from our releases page.

usage

The CLI is designed to be as minimal and straightforward as the algorithm itself.

compressing data

iris compress input.bin output.iris

decompressing data

iris decompress output.iris original.bin

system requirements

FFmpeg: Required as an orchestrator. Ensure it has NVENC support and is in your PATH.

NVIDIA GPU: An RTX 4000+ unlocks blistering av1_nvenc hardware acceleration. RTX 3000 cards use hevc_nvenc.

CPU Fallback: No GPU? Iris seamlessly reroutes compression through your CPU using libsvtav1.
